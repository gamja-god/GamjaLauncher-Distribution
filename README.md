# Gamja Launcher

A custom Minecraft: Java Edition launcher for the Gamja Server community in South Korea.

## About

Gamja Launcher is an independent, community-focused desktop launcher based on the open-source Helios Launcher.

Our goal is to provide a convenient and consistent gameplay experience for our community members.

## Planned Features

- Minecraft: Java Edition 1.21.5 with Fabric
- Microsoft account authentication
- Minecraft ownership verification
- Automatic mod installation and updates
- Managed configuration files
- Direct connection to our community server
- Custom launcher interface

## Authentication & Security

The launcher is designed for legitimate Minecraft owners and uses Microsoft authentication without collecting account passwords or bypassing Minecraft licensing requirements.

## Development Status

Currently under development. Minecraft Java Edition game service API approval is required before public release.

## Credits
